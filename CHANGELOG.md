# Changelog

## Initial public release

- Curated ABI function surfaces for community integrations.
- Shared RPC chain detection and network configuration validation.
- Clone-and-run documentation and formatting/lint tooling.
- Added position, pending-order and PnL snapshots; position-aware close;
  owner lifecycle commands; regression coverage; and an opt-in local fork suite.
- Added a read-only Pyth/OracleRouter compatibility check and documented its
  boundary relative to funded trade testing.
- IMP/CMP preparation, funding, market and limit order examples with
  simulation by default.
- Apache-2.0 licensing.
